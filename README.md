# QuickBMICalc

A fast, lightweight, and privacy-focused Body Mass Index (BMI) calculator built with [Astro](https://astro.build).

## Features

- ⚡️ **Instant Calculation**: Instant BMI results with metric (kg/cm) and imperial (lbs/ft/in) unit toggles.
- 🎨 **Modern UI**: Dark/Light mode support, responsive layout, and visual BMI category indicators.
- 🔒 **100% Private**: Client-side calculation with zero analytics or tracking.
- 📱 **PWA Ready**: Offline support with service worker and web app manifest.
- 🚀 **SEO Optimized**: Complete Open Graph, Twitter cards, and Schema.org structured data.

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/Vinod-Nex/QuickBMICalc.git
cd QuickBMICalc
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

Configured for one-click deployment on [Vercel](https://vercel.com).
